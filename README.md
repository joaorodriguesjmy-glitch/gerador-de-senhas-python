# Gerador de Senhas em Python

Projeto em Python para gerar senhas aleatórias e seguras com escolha de tamanho e tipos de caracteres (letras maiúsculas, números e símbolos).

## Funcionalidades

- Escolha do tamanho da senha (com ajuste automático para no mínimo 8 caracteres se o valor informado for menor que 4).
- Opção de incluir ou não letras maiúsculas, números e símbolos especiais.
- Uso do módulo `secrets`, indicado para geração segura de senhas.

## Como executar no VS Code (Jupyter Notebook)

1. Abra a pasta do projeto no **VS Code**.
2. Abra o arquivo `gerador_senhas.ipynb`.
3. Selecione um kernel Python e execute a célula com `Shift + Enter`.
4. Responda às perguntas exibidas para gerar sua senha.
